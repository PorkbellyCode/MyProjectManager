# MyProjectManager 디자인 규칙 (초안)

- 기준 시안: **A. 구조형** (디자인 캔버스 "MyProjectManager 디자인 시안"의 A 아트보드)
- 상태: **확정** (2026-11-24, 형준)
- 표기: [결정] 형준이 정한 것 / [Claude 결정] 시안 작업에서 정한 값

## 1. 원칙 [결정]
1. **가시성, 가독성이 먼저**다. 장식보다 정보가 먼저 눈에 들어와야 한다.
2. **깔끔하고 여백이 넉넉하게.** 촘촘한 표보다 숨 쉬는 목록.
3. **움직임은 깔끔하게.** 상태가 바뀌었다는 걸 알려주는 데만 쓰고, 화려하게 쓰지 않는다.
4. 좋아하는 서비스: Jira(구조), Notion(여백과 문서감).

## 2. 레이아웃 [결정: A 구조]
- 상단 바: 로고 · 프로젝트 이름 / 가운데 검색(`Ctrl K`) / 알림 · 테마 전환 · 사용자.
- 티켓 화면은 3단: **목록(380~460px) | 본문과 활동(가변) | 속성 패널과 처리 버튼(280~340px)**.
- 좁은 화면에서는 목록 → 본문 → 속성 순으로 아래로 쌓인다.
- 본문 영역 안쪽 여백 40~48px, 목록 행 높이는 두 줄(제목 + 메타) 기준.

## 3. 색
### 3.1 강조색 = AI 제공자 색 [결정]
- 프로젝트의 **기본 강조색은 리드가 고른 AI 제공자를 따른다.** 사용자는 자기 화면에서 강조색을 바꿀 수 있다.

| 제공자 | 라이트 | 다크 |
|---|---|---|
| Claude | `#C2410C` 어두운 오렌지 | `#EF7D3C` |
| ChatGPT | `#0F766E` 옥색 | `#2DD4BF` |
| Gemini | `#1D4ED8` 파랑 | `#6FA3FF` |

- [Claude 결정] "프로젝트의 AI 제공자"는 프로젝트 설정의 **기본 AI 제공자**(Claude / ChatGPT / Gemini)다(인터뷰 설계 6절). 개별 에이전트가 다른 제공자를 쓰더라도 화면 강조색은 이 설정을 따른다.
- [Claude 결정] 사용자가 고른 강조색은 사용자 설정에 저장하고 모든 프로젝트에 적용한다. 지우면 프로젝트 기본값으로 돌아간다.
- [Claude 결정] 강조색은 **주요 버튼, 선택 표시, 알림 점**에만 쓴다. 넓은 면적에 칠하지 않는다.

### 3.2 바탕색 [Claude 결정]
| 토큰 | 라이트 | 다크 |
|---|---|---|
| bg | `#FAFAF9` | `#0F0E0D` |
| surface | `#FFFFFF` | `#171615` |
| sunken | `#F4F3F1` | `#201E1C` |
| text | `#1C1917` | `#F5F5F4` |
| muted | `#57534E` | `#C9C4BF` |
| faint | `#736C66` | `#A39E98` |
| border | `#E7E5E4` | `#2F2C29` |

- 모든 글자는 바탕 대비 4.5:1 이상.
- 상태는 색 점 + 글자로 표시한다(색만으로 구분하지 않음). 긴급도는 색이 아니라 **막대 4개 높이**로 표시한다. 강조색이 제공자마다 바뀌므로 상태·긴급도가 강조색과 겹치지 않게 하려는 것이다.

## 4. AI가 한 일의 표시 [결정: 제공자 색 / Claude 결정: 형태]
- AI 표시 색은 **그 판단을 실제로 만든 제공자의 색**을 쓴다. 검토는 Claude, 분류는 ChatGPT처럼 역할마다 다르면 각각의 색으로 보인다.
- 강조색과 AI 색이 같은 계열이 될 수 있으므로, AI 표시는 **색이 아니라 형태로 구분**한다.
  - 반짝이 아이콘 ✦ + 제공자 이름("Claude 검토", "AI 배정")
  - 연한 바탕(tint)과 얇은 테두리(ring). 진한 면은 쓰지 않는다(진한 면은 강조색 버튼 전용).
  - 활동 목록에서 AI 항목의 아바타는 원 안의 반짝이 아이콘, 사람은 이름 첫 글자.
- 사람의 결정과 AI의 결정이 같은 속성을 바꿨다면(예: 긴급도), 값 옆에 "AI 조정" 칩을 붙인다. 리드가 되돌리면 칩이 사라진다.

| 제공자 | tint(라이트/다크) | ring(라이트/다크) | 글자(라이트/다크) |
|---|---|---|---|
| Claude | `#FBEFE9` / `#2A1B15` | `#F1CDBD` / `#5A3324` | `#97401F` / `#F2A98A` |
| ChatGPT | `#E7F6F0` / `#0F2620` | `#B5E2D2` / `#1F5546` | `#0A6650` / `#62D6B3` |
| Gemini | `#EEF3FE` / `#121B2E` | `#C7D6FB` / `#23365E` | `#1E40AF` / `#8DB4FF` |

## 5. 글꼴 [결정: 개발자 친화 / Claude 결정: 조합]
- JetBrains Mono에는 한글 글자가 없어서 조합으로 쓴다.
  - 한글 본문과 제목: **IBM Plex Sans KR** (400/500/600)
  - 번호(MPM-7), 시각, 커밋 SHA, 지시사항 버전, 단축키: **JetBrains Mono**
- 크기: 제목 30 / 섹션 15~18 / 본문 15~16(줄간격 1.7~1.75) / 메타 12~13.

## 6. 모양 [Claude 결정]
- 모서리: 버튼·입력 8~10px, 카드 14px, 칩 999px.
- 테두리 1px `border`, 그림자는 쓰지 않는다(다크에서 깨끗하게 보이도록).
- 간격 단위 4px, 주로 8/12/16/24/32/40.

## 7. 움직임 [결정: 깔끔한 동적 효과 / Claude 결정: 값]
- 블록 등장 `rise`: 0.5초, 6px 위로, 곡선 `cubic-bezier(.2,.8,.2,1)`. 상세 화면은 본문 → AI 카드 → 활동 순으로 0.08초씩 늦게.
- 버튼 hover 1px 떠오름, 0.12초.
- 상태 배지 변경은 색 점이 0.3초 바뀌는 정도만.
- 테마 전환 배경·글자색 0.3초.
- `prefers-reduced-motion`이면 전부 끈다.

## 8. 하지 않는 것
- shadcn 기본 테마 그대로 쓰기
- 그라데이션 배경, 이모지 아이콘, 왼쪽 굵은 띠 카드
- 넓은 면을 강조색으로 칠하기
- 색만으로 상태나 AI 여부를 구분하기
